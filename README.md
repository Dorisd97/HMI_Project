# The Enron Files: A Narrative Investigation

This project is a Streamlit-based web application for exploring, analyzing, and visualizing the Enron email dataset. It provides interactive dashboards, AI-generated summaries, entity relationship networks, and advanced analytics to support narrative investigations.

## Features

- **Dashboard:** High-level statistics, clustering, topic modeling, and entity co-occurrence heatmaps.
- **AI Summary:** Executive summaries generated by local LLMs (Ollama + LangChain).
- **Investigation Files:** Browse and search original machine-generated thematic stories.
- **Event Timeline:** Visualize spikes in email activity and investigate key events.
- **Entity Relationship Network:** Interactive network graphs of story entities and actors.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/HMI_Project.git
   cd HMI_Project
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

   Additional requirements for advanced features:
   ```bash
   pip install scikit-learn minisom plotly pyvis langchain langchain-community
   ```

3. **(Optional) Set up Ollama for local LLMs:**

   **Install Ollama:**

   - **Windows:**  
     Download and run the installer from [https://ollama.com/download](https://ollama.com/download).

   - **macOS:**  
     Download and run the installer from [https://ollama.com/download](https://ollama.com/download)  
     or install via Homebrew:  
     ```bash
     brew install ollama
     ```

   - **Linux:**  
     Run the following command in your terminal:  
     ```bash
     curl -fsSL https://ollama.com/install.sh | sh
     ```

   **Start the Ollama server and pull the required model (e.g., `mistral`):**
   ```bash
   ollama run mistral
   ```

4. **Prepare data:**
   - Place the required data files (JSON, pickle, etc.) in the appropriate directories as specified in `src/config/config.py`.

5. **Run the app:**
   ```bash
   streamlit run src/app.py
   ```

## Usage

- Use the sidebar to navigate between different analysis views.
- Some features require precomputed data files (e.g., `.pkl` files). If missing, the app will attempt to generate them.
- For AI summary features, ensure Ollama is running and the required models are available.

## Customization

- Modify `src/config/config.py` to change file paths or settings.
- Add your own data preprocessing scripts in `src/preprocessing/`.
- Customize the UI by editing `style.css`.
